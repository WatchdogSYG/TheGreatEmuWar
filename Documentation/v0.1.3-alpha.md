# Release Notes - The Great Emu War
## Developer Summary
In terms of content, we now have a high-damage grenade, a sprint resource and an upgraded start menu. The grenade and sprint resource is part of an ability system where abilities go through a cycle of Casting, Firing/Channelling, Recovering, and Cooldown phases, each absorbing some resources if set. The start menu is now full-screen and includes a finished front page, and a second page for a multiplayer lobby. Its technically functional (including LAN and SteamSubsystem connections), but needs important bug fixes and UI feedback to be able to include in an update. Luckily it all works on single player so I have simply disabled the listen server capabilities for this update.
## Balancing
Not much has changed really, but there may be minor differences in bullet penetration values because some weird stuff happened to the DataTable asset and I couldn't recover it so I just remade it from memory.
- Added Grenade on E. 500 Damage in a sphere after a timer.
- Sniper base damage increased to 800.
## Features & Content
- Buying a weapon now equips it in your empty slot if there is an empty slot.
- Better Start Menu
- If Steam is active, the game will populate the Friends List.
- Grenade, Sprint, and Melee are now abilities.
	- Grenade has a cast time, non-channeling fire, a recovery, and a long cooldown time. It does not consume Ammo.
	- Sprint is a Channeling ability. It only consumes Mana if it is active and the player is moving forward.
	- Melee has a cast time, non-channeling fire, a recovery, and a short cooldown time. It does not consume Ammo.
