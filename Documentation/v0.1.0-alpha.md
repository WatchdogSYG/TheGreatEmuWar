# Release Notes - The Great Emu War
## Developer Summary
Welcome to the release notes for my game!

This game was inspired by a conversation I had with someone completely unfamiliar with the Australian's humiliating defeat against the emus. In Australia, its generally common knowledge as a fun trivia fact that most people have heard of so it was surprising that this - relatively well cultured - person hadn't heard of it. Upon looking it up on Google, we could really only find a wiki article and a handful of random YouTube videos on the subject, and the challenge was then set to make some sort of content on the topic.

I am a fan of arcade / hero / ability shooters and have wanted to make one of scale and success some time. This game is a perfect step towards that goal - I dub that overarching project "Echo". This game's purpose is twofold. One is to capture the tail end of the natural conversation on the Emu War topic, and the other is to be a subset of the shooter game I want to make. This game will continue to be developed with features and technology I intend to exist in Project Echo. In other words, the Emu game will be developed in the Echo framework so both games will benefit from shared code. At some point in the future, this game will have enough features to where I feel appropriate to polish the game to gold status and release a full version and then stop development.

The gameplay is inspired by Call of Duty's Zombies mode, where waves of melee-based enemies try to swarm the player with increasing health and speed as the waves progress. The player gains points when damaging and killing enemies and is able to use points to buy better weapons, open more play areas, and upgrade their character. Historically, the invading Emu population were after farmed wheat, which presents the setting and secondary objective for the Emus. The twist is that I intend for the game to have a wave-survival component (zombies) and a tower defence component (wheat stash).

I have set up a template for these release notes, which are intended to document and display the development progress I make. A separate portfolio/technical documentation thread will be maintained in another format I am yet to determine. As this is the first entry, the template doesn't really apply so I am just including a non-exhaustive list of feature ideas for v1.0.

Feel free to message me about anything.
