# Release Notes - The Great Emu War
## Developer Summary
This update mainly focuses on an improved art pass on the map including fog, foliage, water, structures, themed props, and blockouts. There is also an introduction of bullet penetration and surrounding damage system.
## Balancing
- Purchase cost of SMG reduced from 2750 to 2500.
- Damage of Sniper decreased from 400 to 300.
- Added bullet penetration to Sniper.
## Features & Content
- Environment, volumetric fog and foliage improvements.
- Blockout of future map areas.
- Advanced damage system. Now the game can roll for crits and apply bullet penetration factors to each damage instance.
- Added melee animation.
## Bug Fixes
- End of game menu now shows proper score.
- Map collision improved.
	- Player is not allowed outside map bounds.
	- Player-spawned projectiles do not collide with player-blocking volumes.
	- Emu navmesh pathfinding accounts for the above two improvements.
-  Lots more (I didn't document these properly).
## Technical
- Damage System
	- Each hitscan has an intrinsic penetration factor and each `Damageable` actor also has an intrinsic penetration resistance. Upon damage, these are multiplied along with the base damage to calculate the next base damage application. All penetrable map geometry has `PenetrationFactor = 0.5` for now. There is a cap on the number of Actors penetrated per attack.
	- Each attack has a critical hit rate. If the attack was not already critical (i.e. a headshot), the attack can roll for a critical hit and apply it. All critical hit probabilities set to zero right now but it was tested.
