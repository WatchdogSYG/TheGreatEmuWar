# The Great Emu War
Unreal Engine 5 Game

Experience the "historically accurate" retelling of the heroics displayed by the Australian Military Forces of 1932 battling against the evil Emu Alliance.

Survive wave-based shooter combat as a soldier defending the town's crops. Gameplay inspired by cod zombies.
